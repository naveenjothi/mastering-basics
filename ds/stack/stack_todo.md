# 🧗 Stack Mastery Journey — STACKQUEST

## 🎯 Goal:

Become confident with all stack-based problems asked in interviews (DSA rounds + system-based).

## 📅 Duration: 7 Days Plan (2 hours/day)

With boss fights, XP points, badges, and power-ups.

---

## 🗺️ Roadmap: Climb the Tower of Stacks

Each level gives you XP + unlocks concepts and patterns.

**🧠 Concepts:**

- What is Stack?
- LIFO
- Stack Operations (Push, Pop, Peek, Size, isEmpty)
- Array vs Object Implementation

**🎮 Tasks (XP: 100):**

- [x] Implement stack using array (25 XP)
- [x] Implement stack using object (25 XP)
- [x] Reverse a string using stack (20 XP)
