# 🧠 14-Day Sorting Algorithms Learning Plan (Gamified)

🎯 **Goal**: Learn and implement major sorting algorithms with practice in 2 weeks  
🎮 **XP Target**: 300 XP to unlock "Sorting Master" 🏅

---

## 📅 Week 1: Basics + Divide & Conquer

### ✅ Day 1: Introduction to Sorting (10 XP)

- [ ] Watch a video on why sorting matters
- [ ] Read overview of sorting algorithm types
- [ ] Note real-world sorting use cases

### ✅ Day 2: Bubble Sort (15 XP)

- [ ] Understand the algorithm
- [ ] Dry run with example
- [ ] Code it in your preferred language (e.g., JS or Go)

### ✅ Day 3: Selection Sort (15 XP)

- [ ] Learn how it works (find min repeatedly)
- [ ] Compare with Bubble Sort
- [ ] Implement and test

### ✅ Day 4: Insertion Sort (15 XP)

- [ ] Understand how it mimics real-world sorting (like cards)
- [ ] Implement with dry run
- [ ] Code it and compare with previous sorts

### ✅ Day 5: Practice Day 1 (20 XP)

- [ ] Solve 3 easy sorting problems on LeetCode/HackerRank
- [ ] Track time taken & number of attempts

### ✅ Day 6: Merge Sort (20 XP)

- [ ] Understand divide-and-conquer paradigm
- [ ] Visualize recursive calls
- [ ] Implement Merge Sort

### ✅ Day 7: Quick Sort (20 XP)

- [ ] Learn pivot-based partitioning
- [ ] Dry run with different pivots
- [ ] Code it and test on arrays

---

## 📅 Week 2: Advanced Sorts + Application

### ✅ Day 8: Time & Space Complexity (20 XP)

- [ ] Create table comparing all sorting algorithms
- [ ] Note best/worst/average cases
- [ ] Add stable vs unstable info

### ✅ Day 9: Recap + Quiz (20 XP)

- [ ] Review all algorithms
- [ ] Take a sorting quiz (MCQs/Flashcards)
- [ ] Reflect on learning with journal entry

### ✅ Day 10: Heap Sort (25 XP)

- [ ] Learn about heaps and priority queues
- [ ] Implement Heap Sort manually
- [ ] Try with min/max heaps

### ✅ Day 11: Radix Sort & Counting Sort (25 XP)

- [ ] Learn difference from comparison-based sorts
- [ ] Understand use cases (integers, strings)
- [ ] Code both algorithms

### ✅ Day 12: Practice Day 2 (30 XP)

- [ ] Solve 5 problems (easy + medium mix)
- [ ] One must use divide-and-conquer sort (Merge/Quick)

### ✅ Day 13: Final Challenge (40 XP)

- [ ] Implement all sorting algos in one file
- [ ] Create CLI app to select which sort to run
- [ ] Bonus: Add timing comparison for input arrays

### ✅ Day 14: Showcase Day (50 XP)

- [ ] Write a blog or post on LinkedIn/GitHub
- [ ] Include code, what you learned, and favorite algorithm
- [ ] Share your experience and badge!
